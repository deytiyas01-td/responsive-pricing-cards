# 💳 Responsive Product Pricing Cards

A modern and responsive **SaaS pricing card component** built using HTML, CSS, and JavaScript. The project demonstrates commercial UI design practices with an interactive monthly/yearly billing toggle, hover animations, and pricing badges.

## ⚙️ How It Works

The pricing cards display different subscription plans with their respective features and prices.

Users can switch between:

- **Monthly Billing**
- **Yearly Billing**

JavaScript automatically updates the displayed prices when the billing cycle changes.

CSS transitions and transform effects provide interactive animations when users hover over the pricing cards.
